## # 👨🏻‍💻 Leonardo Godoy

**`Desenvolvedor Front-End`**

Me chamo Leonardo Godoy, tenho 21 anos e sou estudante de **Ciência da Computação** na Universidade Católica de Brasília. Sou apaixonado por tecnologia e desenvolvimento de software, sempre buscando transformar ideias em projetos reais e funcionais.

Tenho experiência no desenvolvimento de aplicações web utilizando **HTML, CSS, JavaScript, React e Next.js**, além de conhecimentos em **SQL, C, Supabase e AWS**. Também possuo experiência com versionamento utilizando Git e GitHub e com deploy de aplicações através da Vercel.

Ao longo da minha formação, venho desenvolvendo projetos como sistemas de controle financeiro, aplicações web, sistemas acadêmicos e plataformas utilizando banco de dados e autenticação. Gosto de aprender novas tecnologias na prática e transformar cada projeto em uma oportunidade de evolução.

Atualmente, estou focado em aprimorar minhas habilidades como desenvolvedor, construir projetos cada vez mais completos e conquistar novas oportunidades profissionais na área de tecnologia.
